# Math Game

## How it works
The game will ask you a specified number of math questions between 2 integers. Division questions will ALWAYS result in whole numbers (integers)

You will be presented with a menu to choose which operations you would like your math questions to be:

1) Addition, 2) Subtraction, 3) Multiplication, 4) Division, 5) Random, 6) Previous Results

Type in the respective number to select which math operations you want to answer questions for. Random will simply display math questions of any given operation. 

You will type in the answer to each question in your terminal

After you have answered all questions, your score will pop up, before displaying the menu again.

To exit program use control + c.

Previous results will be stored in a list, and can be viewed using the appropriate menu option at any time.

Previous results will dissapear after exiting game.
